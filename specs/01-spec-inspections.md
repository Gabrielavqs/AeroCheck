# Spec 01 — Controle de Inspeções de Manutenção / Maintenance Inspection Control

**Status:** Aprovada / Approved · **Versão / Version:** 1.0

---

## 1. Problema / Problem

- **PT:** A equipe de manutenção precisa saber, de forma rápida, quais aeronaves da frota têm inspeções pendentes, em andamento ou concluídas, e quais estão com o prazo vencido.
- **EN:** The maintenance team needs to quickly identify which fleet aircraft have pending, in-progress, or completed inspections, and which ones are overdue.

---

## 2. Objetivo / Objective

- **PT:** Permitir cadastrar aeronaves, registrar inspeções e acompanhar o andamento delas em um painel simples.
- **EN:** Allow registering aircraft, logging inspections, and tracking their progress on a simple dashboard.

---

## 3. Fora de escopo (nível básico) / Out of Scope (Basic Level)

- **PT:** Login/perfis de usuário, histórico de alterações, anexos, integração com sistemas reais.
- **EN:** User login/profiles, change history, attachments, integration with real external systems.

---

## 5. Regras de negócio / Business Rules

- **RN1 / BR1:**
  - **PT:** Toda inspeção nasce com status `Pending`.
  - **EN:** Every inspection starts with the `Pending` status.
- **RN2 / BR2:**
  - **PT:** A transição de status só pode seguir `Pending -> InProgress -> Completed`. Qualquer outra é rejeitada (HTTP 400).
  - **EN:** Status transitions can only follow `Pending -> InProgress -> Completed`. Any other transition is rejected (HTTP 400).
- **RN3 / BR3:**
  - **PT:** Ao iniciar uma inspeção (`InProgress`), a aeronave passa a `InMaintenance`.
  - **EN:** When starting an inspection (`InProgress`), the aircraft status changes to `InMaintenance`.
- **RN4 / BR4:**
  - **PT:** Ao concluir uma inspeção, se a aeronave não tiver outra inspeção `InProgress`, volta a `Operational`.
  - **EN:** When completing an inspection, if the aircraft has no other `InProgress` inspection, it returns to `Operational`.
- **RN5 / BR5:**
  - **PT:** Uma inspeção é considerada **atrasada** quando `DueDate` é anterior a hoje e o status não é `Completed`.
  - **EN:** An inspection is considered **overdue** when `DueDate` is earlier than today and the status is not `Completed`.
- **RN6 / BR6:**
  - **PT:** Não é permitido cadastrar duas aeronaves com a mesma matrícula (HTTP 409).
  - **EN:** Registering two aircraft with the same registration number is not allowed (HTTP 409).

## 6. Critérios de aceitação / Acceptance Criteria

### CA1 — Cadastrar aeronave / Register Aircraft
- **PT:** Dada uma matrícula válida e inédita, quando eu cadastro a aeronave, então ela aparece na lista com status `Operational`.
- **EN:** Given a valid and unique registration, when I register the aircraft, then it appears in the list with `Operational` status.
- **PT:** Dada uma matrícula já existente, quando eu cadastro, então recebo erro 409 e uma mensagem clara na tela.
- **EN:** Given an already existing registration, when I submit the registration, then I receive a 409 error and a clear message on the screen.

### CA2 — Registrar inspeção / Log Inspection
- **PT:** Dada uma aeronave existente e dados válidos, quando registro a inspeção, então ela aparece como `Pending`.
- **EN:** Given an existing aircraft and valid data, when I log the inspection, then it appears as `Pending`.

### CA3 — Atualizar andamento / Update Progress
- **PT:** Dada uma inspeção `Pending`, quando clico em "Iniciar", então ela vira `InProgress` e a aeronave vira `InMaintenance`.
- **EN:** Given a `Pending` inspection, when I click "Start" ("Iniciar"), then it becomes `InProgress` and the aircraft becomes `InMaintenance`.
- **PT:** Dada uma inspeção `InProgress`, quando clico em "Concluir", então ela vira `Completed` e a aeronave volta a `Operational` (se não houver outra em andamento).
- **EN:** Given an `InProgress` inspection, when I click "Complete" ("Concluir"), then it becomes `Completed` and the aircraft returns to `Operational` (if no other inspection is in progress).
- **PT:** Dada uma inspeção `Completed`, então nenhuma ação de andamento é oferecida.
- **EN:** Given a `Completed` inspection, then no progress action is offered.

### CA4 — Painel / Dashboard
- **PT:** O painel mostra: total de aeronaves, aeronaves em manutenção, inspeções pendentes, em andamento e atrasadas.
- **EN:** The dashboard displays: total aircraft, aircraft in maintenance, pending inspections, in-progress inspections, and overdue inspections.

### CA5 — Filtro / Filter
- **PT:** A lista de inspeções pode ser filtrada por status.
- **EN:** The inspection list can be filtered by status.

- **PT:** Navegação com 3 telas: **Painel**, **Inspeções**, **Aeronaves**.
- **EN:** Navigation with 3 screens: **Dashboard** (Painel), **Inspections** (Inspeções), **Aircraft** (Aeronaves).
- **PT:** Cada tela trata: carregando, erro (com botão "Tentar novamente") e lista vazia.
- **EN:** Each screen handles: loading, error (with a "Try again" / "Tentar novamente" button), and empty list states.
- **PT:** Status exibidos com selo de texto + cor; atrasadas recebem selo "Atrasada".
- **EN:** Statuses displayed with text + color badges; overdue items receive an "Overdue" ("Atrasada") badge.GIT
