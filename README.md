## 🇺🇸 English

Aviation maintenance inspection tracking system designed to monitor fleet aircraft and ensure strict inspection workflows (A-Check, C-Check, and Structural inspections).

### Stack
* **Back-end:** C# / .NET 8 (Web API, Entity Framework Core)
* **Database:** SQL Server 2022
* **Front-end:** React + Next.js 14 (App Router) + TypeScript
* **Methodology:** Spec-Driven Development (SDD)

*Project under development.*

* **Banco de Dados:** SQL Server 2022
* **Front-end:** React + Next.js 14 (App Router) + TypeScript
